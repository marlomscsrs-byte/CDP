# CDP — Sistema de Instrutores

Frontend preparado para hospedagem estática no GitHub Pages.

## Arquitetura

- Frontend: GitHub Pages
- Backend: Google Apps Script
- Banco: Google Sheets
- Render/PostgreSQL: não utilizado pelo frontend

## Configuração

Edite `config.js` e preencha `API_BASE_URL` com a URL `/exec` do Web App do Google Apps Script quando o backend estiver pronto.

Não coloque senhas, tokens, webhooks ou outras credenciais neste repositório.
